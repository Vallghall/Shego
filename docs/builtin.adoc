:toc: left

== Overview

The `pkg/builtin` package provides built-in Scheme procedures organized into subpackages by category. It follows a modular design where each subpackage defines related operations.

== Package Structure

----
pkg/builtin/
├── builtin.go      # Main entry point, aggregates all subpackages
├── aryth/          # Arithmetic operations
│   └── aryth.go
└── cmp/            # Comparison operations
    └── cmp.go
----

== Main Package

=== Loading Builtins

The main `builtin` package provides a function to get all built-in definitions:

[source,go]
----
// All returns all built-in definitions
func All() []mem.Definition
----

=== Usage

[source,go]
----
import (
    "github.com/Vallghall/schego/pkg/builtin"
    "github.com/Vallghall/schego/pkg/eval"
)

evaluator := eval.New()
if err := evaluator.State().LoadBuiltins(builtin.All); err != nil {
    // Handle error
}
----

== Arithmetic Subpackage (aryth)

The `aryth` subpackage provides numeric operations.

=== Exported Function

[source,go]
----
func Definitions() []mem.Definition
----

=== Procedures

[cols="1,1,3"]
|===
| Name | Arity | Description

| `+`
| variadic
| Sum of all arguments (0 with no args)

| `-`
| 1+
| Negation with 1 arg, subtraction with 2+

| `*`
| variadic
| Product of all arguments (1 with no args)

| `/`
| 1+
| Reciprocal with 1 arg, division with 2+

| `modulo`
| 2
| Integer remainder (Scheme semantics)

| `abs`
| 1
| Absolute value

| `min`
| 1+
| Minimum of arguments

| `max`
| 1+
| Maximum of arguments
|===

=== Examples

[source,scheme]
----
(+ 1 2 3)           ; => 6
(+)                  ; => 0
(- 5)                ; => -5
(- 10 3 2)           ; => 5
(* 2 3 4)            ; => 24
(*)                  ; => 1
(/ 2)                ; => 0.5
(/ 24 2 3)           ; => 4
(modulo 10 3)        ; => 1
(abs -5)             ; => 5
(min 3 1 4 1 5)      ; => 1
(max 3 1 4 1 5)      ; => 5
----

== Comparison Subpackage (cmp)

The `cmp` subpackage provides comparison and predicate operations.

=== Exported Function

[source,go]
----
func Definitions() []mem.Definition
----

=== Numeric Comparisons

[cols="1,1,3"]
|===
| Name | Arity | Description

| `=`
| 2+
| Numeric equality (all equal)

| `<`
| 2+
| Strictly increasing

| `>`
| 2+
| Strictly decreasing

| `\<=`
| 2+
| Non-decreasing

| `>=`
| 2+
| Non-increasing
|===

=== Numeric Predicates

[cols="1,1,3"]
|===
| Name | Arity | Description

| `zero?`
| 1
| True if argument is zero

| `positive?`
| 1
| True if argument is positive

| `negative?`
| 1
| True if argument is negative
|===

=== General Predicates

[cols="1,1,3"]
|===
| Name | Arity | Description

| `eq?`
| 2
| Identity comparison (pointer/symbol ID)

| `equal?`
| 2
| Structural equality

| `not`
| 1
| Boolean negation
|===

=== Examples

[source,scheme]
----
(= 1 1 1)            ; => #t
(< 1 2 3)            ; => #t
(> 3 2 1)            ; => #t
(<= 1 1 2)           ; => #t
(zero? 0)            ; => #t
(positive? 5)        ; => #t

(not #f)             ; => #t
(eq? 'a 'a)          ; => #t
(equal? '(1 2) '(1 2)) ; => #t
----

== Creating New Builtins

=== Step 1: Create Subpackage

Create a new directory and file:

[source,go]
----
// pkg/builtin/myops/myops.go
package myops

import "github.com/Vallghall/schego/pkg/mem"

func Definitions() []mem.Definition {
    return []mem.Definition{
        {Name: "my-proc", Value: mem.NewPrimitive("my-proc", 1, myProc)},
    }
}

func myProc(args []mem.Object) (mem.Object, error) {
    // Implementation
    return mem.Void, nil
}
----

=== Step 2: Register in Main Package

Update `pkg/builtin/builtin.go`:

[source,go]
----
import (
    "github.com/Vallghall/schego/pkg/builtin/myops"
    // ...
)

func All(pool *atom.Pool) []eval.Definition {
    var defs []eval.Definition
    // ...
    defs = append(defs, myops.Definitions(pool)...)
    return defs
}
----

== Primitive Function Signature

All primitive functions must match the `mem.PrimitiveFunc` signature:

[source,go]
----
type PrimitiveFunc func(args []Object) (Object, error)
----

=== Parameters

- `args`: Slice of evaluated arguments

=== Return Values

- `mem.Object`: Result value (use `mem.Void` for side-effect operations)
- `error`: Any error that occurred

NOTE: Primitive functions are intentionally decoupled from the `eval` package.
They only depend on `mem` for object types and `atom` for symbol interning.
This design allows the builtin packages to be used without any circular dependencies.

=== Error Types

Use appropriate error types from `pkg/mem`:

[source,go]
----
// Type mismatch
mem.NewTypeError(mem.TypeNumber, arg.Type(), "")

// Wrong argument count
mem.NewArityAtLeastError("proc-name", minimum, len(args))
mem.NewArityError("proc-name", expected, len(args))

// Division by zero
&mem.DivisionByZeroError{}
----

== Design Principles

=== Modularity

Each subpackage is self-contained and only exports its `Definitions` function. This allows:

- Easy addition of new categories
- Independent testing
- Clear organization

=== Type Safety

All primitives perform explicit type checking:

[source,go]
----
n, err := mem.AsNumber(args[0])
if err != nil {
    return nil, mem.NewTypeError(mem.TypeNumber, args[0].Type(), "")
}
----

=== Variadic Handling

Variadic procedures use arity `-1`:

[source,go]
----
mem.NewVariadicPrimitive("name", eval.PrimitiveFunc(fn))
----

The function is responsible for validating minimum argument counts.

=== Scheme Semantics

Operations follow Scheme semantics:

- Only `#f` is falsy
- Empty list `()` is truthy
- `modulo` follows Scheme sign conventions
